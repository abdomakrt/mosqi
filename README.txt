# نظام توزيع الخطباء على المساجد

**المؤلف:** MiniMax Agent  
**التاريخ:** 2025-10-30

## نظرة عامة

نظام ويب ذكي ومتطور لإدارة توزيع الخطباء على المساجد بطريقة عادلة ومنظمة. يضمن النظام وصول كل خطيب لجميع المساجد بموضوعه الحالي قبل الانتقال لموضوع جديد، مع توفير نظام راحة دورية وضمان تغطية جميع المساجد كل جمعة.

## 🌟 المميزات الرئيسية

### ✅ التوزيع الذكي
- **دورة شاملة**: كل خطيب يزور جميع المساجد بموضوعه الحالي
- **تجنب التكرار**: عدم تكرار زيارة نفس المسجد بنفس الموضوع
- **تتبع المسارات**: تسجيل دقيق للمساجد التي زارها كل خطيب
- **تغيير المواضيع**: تنبيه تلقائي عند الانتهاء من جميع المساجد

### ✅ إدارة المرونة
- **خطباء جدد**: إمكانية تحديد المساجد المزارة مسبقاً
- **راحة دورية**: أسبوع راحة لكل خطيب كل 3 أسابيع
- **تغطية كاملة**: ضمان وصول خطيب لجميع المساجد كل جمعة
- **إلغاء وإضافة**: مرونة في إدارة التعيينات

### ✅ واجهة حديثة
- **تصميم عربي**: واجهة كاملة باللغة العربية
- **متجاوب**: يعمل على جميع الأجهزة (هاتف، تابلت، كمبيوتر)
- **سهل الاستخدام**: تصميم بديهي وواضح
- **مؤشرات بصرية**: أشرطة تقدم وإحصائيات ملونة

### ✅ إدارة البيانات
- **قاعدة بيانات موثوقة**: SQLite للحفظ المحلي
- **سجل شامل**: حفظ تاريخ جميع التعيينات
- **نسخ احتياطية**: إمكانية تصدير واستيراد البيانات
- **أمان البيانات**: حماية من الحذف العرضي

## 📋 المتطلبات

### البرمجيات المطلوبة:
- **Python 3.8+**
- **Flask 2.3+**
- **Flask-SQLAlchemy 3.0+**
- **Bootstrap 5.3+** (مدمج عبر CDN)

### المتطلبات التقنية:
- **نظام التشغيل**: Windows, macOS, Linux
- **الذاكرة**: 512 MB RAM كحد أدنى
- **التخزين**: 100 MB مساحة فارغة
- **الشبكة**: إنترنت للتحميل الأولي للـ Bootstrap

## 📖 دليل الاستخدام

### الصفحة الرئيسية
- **إحصائيات عامة**: عدد المساجد، الخطباء، والتعيينات
- **مميزات النظام**: شرح مفصل لكيفية عمل النظام
- **إجراءات سريعة**: روابط مباشرة لجميع الوظائف

### إدارة المساجد
1. **إضافة مسجد جديد**:
   - انقر على "إضافة مسجد جديد"
   - أدخل اسم المسجد (مطلوب)
   - أدخل العنوان والطاقة الاستيعابية (اختياري)
   - انقر "إضافة المسجد"

2. **تعديل مسجد**:
   - انقر على أيقونة التعديل بجانب المسجد
   - قم بالتعديلات المطلوبة
   - انقر "حفظ التعديلات"

3. **حذف مسجد**:
   - انقر على أيقونة الحذف
   - أكد الحذف (سيتم حذف التعيينات المرتبطة)

### إدارة الخطباء

1. **إضافة خطيب جديد**:
   - انقر على "إضافة خطيب جديد"
   - أدخل اسم الخطيب (مطلوب)
   - أدخل رقم الهاتف والموضوع الحالي
   - **اختياري**: حدد المساجد المزارة مسبقاً
   - انقر "إضافة الخطيب"

2. **متابعة حالة الخطباء**:
   - **أشرطة التقدم**: نسبة إنجاز كل خطيب
   - **الحالات المختلفة**:
     - 🟢 **جاهز**: متاح للتوزيع
     - 🔵 **في راحة**: أسبوع راحة
     - 🟡 **يتغير الموضوع**: انتهى من جميع المساجد

3. **تغيير الموضوع**:
   - انقر على أيقونة التعديل بجانب الخطيب
   - أدخل الموضوع الجديد
   - انقر "تغيير الموضوع"
   - سيتم إعادة تعيين قائمة المساجد المزارة

### التوزيع الأسبوعي

1. **إنشاء توزيع جديد**:
   - انقر على "إنشاء توزيع جديد"
   - حدد تاريخ الجمعة (افتراضي: الجمعة القادمة)
   - انقر "إنشاء التوزيع"

2. **متابعة التوزيع**:
   - عرض التعيينات الحالية
   - اﻻعتذار عن الخطبة هذا اﻻسبوع
   - اﻻعتذار عن هذا المسجد بعينة
   - نسبة التغطية للمساجد
   - تفاصيل كل تعيين (المسجد، الخطيب، الموضوع)

3. **إدارة التعيينات**:
   - **عرض التفاصيل**: معلومات شاملة عن التعيين
   - **تعديل**: تغيير تفاصيل التعيين
   - **حذف**: إزالة التعيين

## ⚙️ آلية العمل

### خوارزمية التوزيع الذكية

#### المرحلة الأولى: التحضير
1. **تحديث أسابيع الراحة**: فحص الخطباء الذين يحتاجون راحة
2. **اختيار الخطباء المتاحين**: استبعاد الذين في راحة
3. **فحص المساجد المزارة**: تحديد المساجد التي لم يزرها كل خطيب

#### المرحلة الثانية: التوزيع
1. **التوزيع الأولي**: كل خطيب يذهب لمسجد لم يزره من قبل
2. **التوزيع التكميلي**: إكمال المساجد المتبقية
3. **حفظ التعيينات**: حفظ في قاعدة البيانات

#### المرحلة الثالثة: المتابعة
1. **تحديث المسارات**: تسجيل المساجد المزارة لكل خطيب
2. **فحص الانتهاء**: تنبيه عند انتهاء خطيب من جميع المساجد
3. **إعادة التعيين**: إعادة تعيين القائمة عند تغيير الموضوع

### مثال عملي

```python
# مثال على دورة كاملة
الخطباء: [أحمد، فاطمة، محمد]
المساجد: [النور، الهدى، الفرقان، التقوى]

# الدورة الأولى
أحمد -> مسجد النور (موضوع: الصبر)
فاطمة -> مسجد الهدى (موضوع: الإحسان)  
محمد -> مسجد الفرقان (موضوع: التوبة)

# الدورة الثانية
أحمد -> مسجد الهدى (موضوع: الصبر)
فاطمة -> مسجد التقوى (موضوع: الإحسان)
محمد -> مسجد النور (موضوع: التوبة)

# حتى انتهاء جميع المساجد...
# ثم تغيير المواضيع وإعادة البدء
```

## 🛠️ الملفات الرئيسية

### app.py
- **التطبيق الرئيسي**: Flask application مع جميع الـ routes

- **خوارزمية التوزيع**: محرك التوزيع الذكي

### Templates (HTML)
- **base.html**: القالب الأساسي مع CSS الشامل
- **index.html**: الصفحة الرئيسية مع الإحصائيات

- **khutbas.html**: إدارة الخطباء مع تتبع التقدم

### static/js/main.js
- **الوظائف الأساسية**: إدارة البيانات والواجهة
- **معالجة الأخطاء**: حماية من الأخطاء
- **تفاعلات المستخدم**: النقرات والتحديثات
- **تصدير البيانات**: PDF, CSV, JSON

## 🔧 استكشاف الأخطاء

### مشاكل شائعة وحلولها

#### 1. خطأ في تشغيل التطبيق
```bash
# المشكلة
ModuleNotFoundError: No module named 'flask'

# الحل
pip install flask flask-sqlalchemy
```

#### 2. قاعدة البيانات لا تُنشأ
```bash
# تأكد من صلاحيات الكتابة في مجلد المشروع
chmod 755 .
```

#### 3. الصفحة لا تظهر بشكل صحيح
- تأكد من تشغيل الخادم على البورت 5000
- تحقق من اتصال الإنترنت لتحميل Bootstrap
- امسح cache المتصفح

#### 4. البيانات لا تُحفظ
- تحقق من وجود ملف قاعدة البيانات
- تأكد من صلاحيات الكتابة
- فحص رسائل الخطأ في terminal
